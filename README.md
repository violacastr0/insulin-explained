# Insulin, Explained

A small educational website comparing three ways to take insulin: a vial and syringe, an insulin pen, and an insulin pump. Each tool is shown on a 3D flip card.

Built as a practice project for my capstone, to demonstrate a professional Git workflow: feature branches, focused commits, pull requests, and merge conflict resolution. See [CONTRIBUTING.md](CONTRIBUTING.md).

This site is for general education only and is not medical advice.

## Run it

Open `index.html` in a browser. No build step needed.
